|---|---|---|---|---|---|

| **DEF-003** | High (Crash) | ATP-008, GEN-004 | In `ai-agents/server.py`, `_generate_fallback_trip_plan` called `float(attr.get("cost"))` on textual strings like `"Free access..."`, crashing fallback generation with `ValueError`. | Added regex/numeric string extraction and `"free"` handling to safely parse cost. | `pytest tests/test_generation_failure.py` PASSED cleanly in 24.8s. |
| **DEF-004** | High (Crash) | ITN-009, ITN-010 | In `TransportService.cs`, `_db.ItineraryItems.Include(i => i.SelectedTransport)` crashed with `InvalidOperationException` because `SelectedTransport` was marked `[NotMapped]`. | Removed invalid `.Include(i => i.SelectedTransport)` and queried `TransportOptions` table directly by `TripId` and date. | `TransportLegTests` PASSED all 4 tests cleanly. |
| **DEF-005** | Medium (Crash) | ATP-003 | In `TripPlannerController.SaveTripPlan`, LINQ query filtered by `t.Destination == destination`, but `Destination` is marked `[NotMapped]`, crashing EF Core SQL translation with 500 error. | Replaced LINQ query with mapped property `t.TripName == tripTitle` and added `[Authorize(Roles = "TourismOperator,Admin,ADMIN")]` to `ItinerariesController.cs`. | `TripPlannerTests.SaveTripPlan_ValidGeneratedPlan_PersistsInDatabase_ATP003` PASSED cleanly. |
